# SHD Builds

Фанатский сайт билдов The Division 2 в стиле интерфейса ИСХ (ISAC / SHD).

## Страницы

| Файл | Что внутри |
|---|---|
| `index.html` | Главная: избранный билд и разделы |
| `settings.html` | Настройки в стиле меню игры: плитки подбора активности, категории со слайдерами характеристик, параметры интерфейса |
| `builds.html` | Список билдов с фильтром по роли |
| `build.html?id=…` | Страница билда: сводка, снаряжение с модалками «где выбить», режимы и тайминги, разбор синергии (у Striker — симулятор стаков) |
| `build-striker.html` | Редирект на `build.html?id=striker` для старых ссылок |
| `gear.html` | База брендов и зелёных комплектов с фильтрами по типу бонуса и источнику |
| `ui-kit.html` | Дизайн-система: палитра, карточки, кнопки, типографика |
| `assets/shd.js` | Общие токены Tailwind, компоненты, фон, шапка с вкладками (A / E) и экран загрузки при переключении вкладок |
| `assets/builds.js` | Данные всех билдов (`SHD_BUILDS`) |

## Стек

Статичный HTML, [Tailwind Play CDN](https://tailwindcss.com/docs/installation/play-cdn) и [Alpine.js](https://alpinejs.dev). Сборка не нужна.

Локальный запуск:

```bash
python -m http.server 8000
```

## Данные

Значения бонусов, таланты и источники дропа — демонстрационные, сверяйте с актуальным патчем. Билды лежат в `assets/builds.js`, бренды и комплекты — в объекте `GEAR` (`gear.html`). Чтобы добавить билд, допишите объект в `MORE_BUILDS` — он сам появится в списке.
